# control_sport — Свой темп

Трекер домашних тренировок, воркаута и калистеники. Один HTML-файл: работает без сборки и сервера приложений.

**Сайт:** [glec1er.github.io/control_sport](https://glec1er.github.io/control_sport/)

## Возможности

- Верх тела по понедельникам и четвергам; низ — по вторникам и пятницам; остальные дни — восстановление.
- Все подходы и отдельный режим тренировки: последовательная запись, повторения, вес, отдых с паузой и пропуском.
- Результат того же подхода предыдущей завершённой тренировки. Для пресса — предыдущая дата любого типа; для остальных упражнений — предыдущий верх или низ.
- Пресс лёжа в первом подходе и на турнике со второго; раздельные графики, рекорды и личные цели.
- История, цели, XP, серии, медали и итоги завершённой тренировки.
- Пошаговая утренняя зарядка, отметка креатина после завершения, самочувствие.
- В дни отдыха — мини-квест: прогулка, спокойная пауза, лёгкая подвижность, индикатор прогресса и +15 XP за закрытый день. Самочувствие и заметка необязательны; серия тренировок не меняется.
- Резервные копии JSON и объединение записей при импорте.

График показывает лучший подход за каждую дату, поэтому линия может снижаться. Рекорд показывает максимум за всё время. Повторения и вес учитываются отдельно.

## Перенос с локального файла

1. Открой прежний локальный трекер в браузере, в котором записывал тренировки.
2. Запиши незавершённый подход и сохрани заметки/цели, если их редактировал.
3. Нажми **«Скачать резервную копию»** и сохрани JSON-файл.
4. Открой сайт и нажми **«Загрузить резервную копию»**, выбери этот файл.
5. Проверь историю, результаты и сообщение **«Сохранено в этом браузере»**.

Локальный файл и HTTPS-сайт имеют разные хранилища браузера. Данные не переносятся автоматически. При первом открытии сайт показывает пустой журнал.

Тренировки хранятся в `localStorage` на конкретном устройстве и в конкретном браузере. Исходный код размещён в GitHub; записи тренировок в репозиторий не отправляются. Между устройствами и браузерами переноси журнал через копию. [Подробности хранения и копий](docs/BACKUPS.md).

## Разработка и проверки

Главный файл — `index.html`; стили, SVG и JavaScript встроены в него. Изменять сайт нужно в этом файле.

Нужен Node.js 20 или новее. Пакеты устанавливать не требуется.

```sh
npm run check
```

Команда проверяет состав сайта, синтаксис скриптов и запускает тесты из `tests/`.

Для локального просмотра:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Затем открой `http://127.0.0.1:8000/`. У локального HTTP-просмотра тоже отдельный журнал.

## GitHub Pages

Источник публикации: ветка **`main`**, папка **`/(root)`**. Файл `.nojekyll` отключает обработку Jekyll. Сайт обновляется после отправки изменений в `main`.

Перед отправкой запусти `npm run check`. Статус публикации находится в **Actions → pages build and deployment** и **Settings → Pages**.

Копии журналов и пользовательские данные не добавляй в Git. В репозиторий входят приложение, тесты и документация.
