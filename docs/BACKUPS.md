# Журнал и резервные копии

Трекер сохраняет записи в `localStorage` под ключом `svoi-temp-workouts-v1`. Формат копии — JSON, версия 1. В копию входят тренировки, веса и повторения, завершения, привычки, план зарядки, цели, самочувствие и настройки.

## Что сохраняется

Во «Всех подходах» корректные значения записываются автоматически. В «Режиме тренировки» введённый результат сохраняется после кнопки записи подхода. Самочувствие и цели сохраняются своими кнопками. Перед обновлением страницы запиши такие поля.

Сообщение «Сохранено в этом браузере» подтверждает запись в локальное хранилище. Если сохранение запрещено или место исчерпано, трекер показывает ошибку и предлагает скачать журнал, пока он доступен в памяти.

## Когда нужна копия

- После новых тренировок и важных правок.
- Перед очисткой данных браузера, сменой браузера или устройства.
- Перед переходом с локального HTML-файла на GitHub Pages.

Кнопка скачивания подготавливает JSON-файл; убедись, что браузер действительно сохранил его. Храни копию вне репозитория, например в личной папке для резервных копий.

## Восстановление

Нажми «Загрузить резервную копию» и выбери JSON-файл. Трекер проверяет формат перед импортом. Корректные записи объединяются с существующими: для совпадающих записей используются более новые метки правок, отдельные даты сохраняются. Повторная загрузка одной копии не удваивает тренировки и награды. Повреждённый файл не заменяет журнал.

После импорта проверь историю и статус сохранения. GitHub Pages не создаёт облачную синхронизацию: у телефона, компьютера и разных браузеров свои журналы. Переноси изменения через свежую копию.

Очистка данных сайта удаляет локальный журнал. В режиме приватного просмотра данные могут исчезнуть после закрытия браузера. Скачанный JSON-файл позволяет восстановить записи.
